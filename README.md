# HR-Analysis-Dashboard

Hello everyone, I hope you're all doing well! 🌟 🚀 
I'm thrilled to share my latest project, HR Analysis, created using the Power BI tool. ✨ 
This dashboard offers invaluable insights into Presence, showcasing metrics such as presence in the office, work-from-home percentages, and SL (Service Level) adherence, all elegantly represented through line charts.
To bring this project to life, I began by collecting data from Kaggle.

 Subsequently, I meticulously cleaned the dataset, crafted essential measures, consolidated data from three Excel sheets into one, and performed transformative operations. A visually engaging dashboard featuring insightful line charts, complemented by tables and slicers for enhanced exploration. 🎇 
Stay tuned for more updates and insights from this project!
